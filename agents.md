# Project Instructions

## General
- Read the existing codebase before making changes.
- Do not unnecessarily rewrite existing working code.
- Follow the existing project architecture.
- Write clean, maintainable, production-quality code.
- Handle edge cases and errors properly.
- Do not hardcode secrets, API keys, passwords, or credentials.

## Development
- Before implementing a feature, inspect related existing code.
- Reuse existing components/services/utilities whenever appropriate.
- Keep frontend and backend responsibilities separated.
- Follow the existing naming conventions.

## Testing
- Run the project's tests after making changes.
- Fix compilation/build errors before finishing.
- Do not consider the task complete if the project does not build.

## Git
- Make changes in a separate branch.
- Keep commits focused and meaningful.
- Do not modify unrelated files.

## Completion
Before finishing:
1. Verify the implementation.
2. Run available tests.
3. Run the build.
4. Check for obvious errors.
5. Summarize all files changed and why.
